# QuizForge

**Create. Challenge. Learn.**

QuizForge is a community-driven quiz platform built with Django. It allows users to create and publish quizzes, challenge themselves with quizzes created by others, track their performance, and share feedback.

## Features

- **User Authentication:** Register, log in, and manage your profile.
- **Quiz Creation:** Create quizzes with multiple-choice questions and four answer options per question.
- **Quiz Management:** Save quizzes as drafts, publish them, and manage existing quizzes.
- **Explore Quizzes:** Browse, search, filter, and sort published quizzes.
- **Timed Assessments:** Attempt quizzes with optional time limits and automatic submission.
- **Instant Results:** View scores, correct answers, and answer explanations through the review interface.
- **Attempt History:** Track previous attempts and performance.
- **Creator Analytics:** Monitor quiz participation and performance.
- **Quiz Reviews:** Allow participants to rate quizzes and leave feedback after completing an attempt.
- **Sample Quizzes:** Explore sample quizzes alongside quizzes created by the community.
- **Admin Panel:** Manage platform data through Django Admin.

## Technology Stack

- **Backend:** Python, Django
- **Database:** PostgreSQL (Supabase)
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Icons:** Bootstrap Icons
- **Deployment:** Render




This project is available for educational and portfolio purposes.
